## 🌟 About the Project

**Cyber Shield Digital Evidence Suite** is a B.Sc. Information Technology academic project developed using Python and Flask.

The application provides a centralized interface to manage cybercrime cases, organize digital evidence, and review recorded system activities. It demonstrates how web technologies and database integration can support a structured digital investigation workflow.

## ✨ Key Features

- 🔑 **Admin Login** — Access the application through an administrator login.
- 📊 **Dashboard** — View the system's main overview.
- 📁 **Case Management** — Organize and review cybercrime cases.
- 📝 **New Case Registration** — Add case details through a web form.
- 📂 **Evidence Management** — Manage digital evidence using the application's interface.
- 🕒 **Activity Log** — Review recorded system activities.
- 🛡️ **Investigation Support** — Keep case and evidence information organized.

## 🚀 Run the Project Locally

**1. Clone the repository**

```bash
git clone https://github.com/rutujathoke43-afk/cyber-shield-digital-evidence-suite.git
```

**2. Open the project directory**

```bash
cd cyber-shield-digital-evidence-suite
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Start the application**

```bash
python app.py
```

**5. Open the local address** shown in the terminal in your browser.
